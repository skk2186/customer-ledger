# V1.0.1 第一轮真实使用反馈修复报告

## 验收结论

**PASS**

本轮仅处理导出设置、桌面易用性、中文界面和 Excel 排版反馈，没有进入新阶段，没有改变账务公式、数据模型或 SQLite 唯一真值原则。

## 修复原因

第一轮真实使用反馈集中在三个方面：导出文件位置和命名不够明确，宽表和返回路径在桌面窗口中不够易用，以及收款对应货款等账务关系的技术表达不适合普通会计。另有 Excel 工作簿列宽、对齐和同名文件覆盖风险需要收紧。

## 修复内容

- 增加导出设置页面。设置以 UTF-8 JSON 原子保存；损坏或不可读时安全回到默认导出目录，不触碰账库、备份或安全锁。自定义目录会创建并进行写入测试，不能使用时明确报错。
- 桌面窗口提供原生目录选择和打开导出文件夹能力；不支持原生选择器时提供路径输入作为回退。导出成功页面显示实际文件名和保存位置，桌面流程不重复触发浏览器下载。
- 三类工作簿使用中文文件名、日期和不覆盖的序号后缀；业务列使用固定宽度、明确的日期和数字格式、适当的对齐和换行策略。
- 所有主要非首页统一提供“返回上一级”和“返回首页”，并按业务层级设置返回目标；宽表保留横向滚动，桌面字号和可读性同步调整。
- 将收款对应关系改为“已用于货款”“剩余预收”“用于某笔货款”“查看对应货款”“取消这笔对应”等用户语言，保留 PaymentAllocation 及原有账务语义。
- 更新 README、用户指南和 Windows 部署说明，补充导出设置、文件命名、目录边界和桌面操作说明。
