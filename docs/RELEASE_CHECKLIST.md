# 阶段五发布前检查清单

本清单只用于后续阶段五的发布准备，不代表阶段四已经开始阶段五工作。

## 数据与迁移

- [ ] 明确生产账库位置、备份目录和权限。
- [ ] 在副本上完成一次迁移升级和重复升级。
- [ ] 验证当前 Alembic 版本与发布代码一致。
- [ ] 确认不会用 `create_all` 替代版本化迁移。
- [ ] 准备脱敏的恢复演练记录。

## 运行与安全

- [ ] 确认正式启动仍只监听本机地址，除非另有书面部署方案。
- [ ] 检查运行目录、导出目录、备份目录和日志目录权限。
- [ ] 确认日志不包含客户名称、完整备注、金额明细或账务行。
- [ ] 确认仓库没有数据库、Excel、备份、日志和敏感样本。
- [ ] 明确管理员如何保留和转移备份文件。

## 功能验收

- [ ] 完成新增客户、发货、收款、分配、预收、作废和撤销流程。
- [ ] 完成备份、修改、恢复、失败回滚和审计核对。
- [ ] 完成三类 `.xlsx` 导出读回检查。
- [ ] 完成真实 `.xls` 文件只读试算，不直接确认导入。
- [ ] 检查中文提示、无意义英文、分页和宽表横向滚动。

## 交付决策

- [ ] 全部自动化测试通过。
- [ ] ruff 和两次迁移检查通过。
- [ ] 本机人工验收记录完整。
- [ ] 性能规模和已知风险已记录。
- [ ] 阶段报告明确 PASS 或 BLOCKED 后，才评估下一阶段工作。
