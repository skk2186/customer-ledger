# Excel 契约（阶段一预留）

阶段一不导入或导出 Excel；本文件只固定未来的边界，避免当前模型被隐式 Excel 规则污染。

## 名称规则

只导出 `.xlsx`。客户 Sheet 名与客户名称完全一致，不静默截断、不自动改名。客户名称去除首尾空白后必须为 1–31 个字符，不含 `: \ / ? * [ ]`、控制字符，且不能以单引号开头或结尾。

## 工作簿结构

- 第一个 Sheet 固定为“客户汇总总表”。
- 每个客户 Sheet 固定 13 列，顺序为：日期、总货款、运费、卸车费、退板吨位、退板金额、问题扣费、平方数、应收款、实收款、欠款、抹零、付款方式。
- 每张客户表最后一行为“合计”。

## 金额与数量

导入导出适配层必须将金额转换为整数分，将吨位和平方数转换为百分之一单位；不得把二进制浮点结果直接写入模型。导入原始文件的指纹和来源键写入 `ImportRecord`，支持重复执行幂等。

## 隐私

真实工作簿只能位于被忽略的 `private_samples/` 或用户明确指定的外部目录，不进入提交、测试样例或阶段报告。
