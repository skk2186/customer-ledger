# 产品规格：阶段一

## 目标

提供一个默认只在本机运行的客户基础台账，先把客户身份、生命周期和后续账务所需的持久化边界固定下来。

## 用户闭环

用户可以查看客户列表、按名称搜索、新增客户、修改名称和备注、归档客户，以及恢复已归档客户。规范化名称在全体客户（包括已归档客户）中唯一。
客户名称去除首尾空白后必须为 1–31 个字符，并直接作为未来 Excel Sheet 名。

## 阶段边界

本阶段不提供发货录入、收款录入、总表汇总、Excel 导入导出、备份恢复或 Windows 打包。账务模型和计算服务只为后续阶段准备并接受自动化测试。

## 规则

- 金额以整数分保存，数量以百分之一单位保存；禁止用浮点数保存金额。
- 负应收可以存在，计算不做零截断。
- 客户不能通过本阶段界面物理删除；有账务历史时服务层明确拒绝物理删除。
- 用户可见错误使用中文业务提示，不显示 SQL、堆栈或数据库异常。
- 名称校验拒绝 Excel 禁止字符、控制字符以及首尾单引号；不截断、不自动改名。
