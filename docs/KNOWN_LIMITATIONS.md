# 已知限制

- 当前发布形态是 Windows onedir，不是单文件 exe；程序目录中的所有文件需要整体保留。
- 数据保存在本机 SQLite，适合单机日常记账；不提供多人并发、云同步或远程访问。
- 程序只监听 127.0.0.1，不提供局域网访问能力。
- 用户数据、备份和导出目录不会随程序目录替换自动迁移；升级时必须保留这些目录。
- Windows 用户目录重定向由系统“文档”位置决定，管理员应确认备份目录有写权限。
- 已在本机 WPS 中验证当前候选导出的工作簿；不同 WPS/Excel 版本仍可能存在显示差异。
- 旧 .xls 导入仍然必须先 Dry Run，再由用户确认；未授权的真实文件不能用于自动化测试。
- 保护标记出现时，系统会优先停止高风险操作，管理员处理完成后才能继续记账。
- 本项目不包含网络备份、自动云端恢复、Windows 安装器或自动更新。
