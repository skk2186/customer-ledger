# 客户快捷填表系统用户指南

## Windows 桌面版启动

解压发布目录后，双击 CustomerLedger.exe。桌面版不需要 Python、命令行或网络连接；程序窗口关闭后，本机服务也会随之关闭。

默认数据位置如下：

- 账库和运行状态：%LOCALAPPDATA%\CustomerLedger
- 备份：“文档\客户账本备份”
- 导出：默认“文档\客户账本导出”，也可以在“导出设置”中选择其他文件夹

升级程序时先关闭旧程序，再替换程序目录中的文件。不要删除或覆盖本机数据目录；首次启动新版本如需升级账库，系统会先保存升级前备份。

## 日常记账

1. 在首页选择“新增一笔”，选择客户并填写发货信息。
2. 如果当天没有收款，初始收款请选择“暂未付款”。系统不会生成一笔 0 元收款。
3. 如果收款超过本单可分配金额，系统会保存完整收款，并把多余部分显示为“未分配预收”。
4. 需要补记收款时，从客户账目选择“新增收款”。可以先保存为预收，之后再分配到有效发货。

## 查看账目

客户账目上方是客户级合计，包括总货款、总应收、总收款、客户净余额和未分配预收。发货明细中的“实收款”和“欠款”只对应有效发货及其有效分配，页脚也是同一口径的有效发货合计。

“欠款”显示为正数时表示仍需收款；显示“已结清”表示本单余额为零；显示“预收/冲减”表示本单派生余额为负。客户级余额为负时显示“预收余额”。作废和撤销只会让记录失效，不会物理删除。

发货明细和收款记录按页显示，使用表格下方的“上一页”“下一页”查看其他记录。宽表可横向滚动。

## 导出

客户账目、客户汇总和全部账目都可以导出为 `.xlsx`。在“导出设置”中可以选择导出文件夹；默认仍是“文档\客户账本导出”。选择后系统会创建并检查文件夹是否可写，设置保存在本机 `settings.json`，不会写入账库。设置文件损坏时会安全回到默认文件夹。

导出文件使用中文名称，例如“客户名称_客户账目_日期.xlsx”“客户汇总总表_日期.xlsx”和“客户账目总表_日期.xlsx”。同一天重复导出会自动追加“_2”“_3”等序号，不会覆盖旧文件。导出成功后页面会显示文件名和完整保存位置，并提供“打开导出文件夹”。每次正式导出前系统会先保存本机账库备份；备份失败时导出不会继续。

除首页外，每个页面顶部都有“返回上一级”和“返回首页”，返回目标按业务页面固定，不依赖浏览器历史记录。

## 备份与恢复

系统会在每天第一次打开时、导入旧账前、导出前和恢复前自动保存备份，也可以在“备份恢复”页面选择“立即备份”。备份只保存在本机配置的备份目录，系统会保留最近的有效应用备份。

恢复操作分两步：先打开备份的“恢复”页面，再勾选“我已确认”并提交。确认前请注意：当前账目会回到该备份保存时的状态。系统会先保存恢复前状态；恢复失败时会自动回滚。

如果备份状态显示“不可恢复”，不要手动修改文件，保留该文件并联系管理员检查本机备份目录。

## 旧账迁移

旧账迁移先做试算预览，预览不会写入账务。只有确认客户映射、异常、付款方式和预收候选后才能确认导入。确认前系统会自动备份；备份失败不会写入导入数据。

## 操作记录

“操作记录”显示新增、修改、作废、分配、导入、备份和恢复等操作的时间与类型。该页面不显示客户备注、金额快照或完整账务数据，也不能删除记录。

## 本机使用提示

系统默认只在本机打开，不依赖网络资源。请定期确认“备份恢复”页面中有最近的有效备份；不要把真实账库、备份、导出文件或旧账文件提交到代码仓库。
